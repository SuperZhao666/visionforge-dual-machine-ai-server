双机推流 · 新手图文教程

先连通画面，
再测试移动。

手机负责接收画面、AI 推理与鼠标控制；电脑端 VF Host 只负责采集、编码和发送画面。 程序优先使用千兆有线链路，没有扩展坞或网线时会自动回退到局域网 UDP 无线推流。

从准备开始 直接看日志反馈
开始前只检查 4 件事
  1. 01手机已安装 VF Mobile
  2. 02电脑已有 VFHost.exe
  3. 03网络选 CAT6 或 UDP
  4. 04控制选 MAKCU 或蓝牙 HID
01

安装与激活

把两个程序准备好

A

安装手机 APP

在手机安装收到的 VF Mobile APK。若系统询问是否允许安装此应用，请确认文件来自官方交付包。

K

激活永久卡密

打开 APP 底部“卡密”页，输入收到的卡密并等待“卡密已激活”。本教程对应永久卡，成功后无需重复输入。

H

放置 Host

把 VFHost.exe 放在电脑桌面。建议保持文件名与位置不变，避免防火墙授权指向旧文件。

授权状态与购买说明不一致？ 先截图“卡密”页面并反馈，不要反复输入卡密，也不要卸载 APP 清除数据。
02

画面传输网络

有线优先，无线自动回退

你有千兆网口扩展坞和网线吗？
有 → 使用 CAT6 有线 没有 → 使用 UDP 无线
推荐 · 更稳定

CAT6 千兆有线

适合追求低延迟和稳定帧率。程序检测到有效有线手机端点后会自动优先使用。

电脑网口网线手机千兆扩展坞USB-C手机
  1. 网线一头插电脑主机网口。
  2. 另一头插手机扩展坞的千兆网口。
  3. 扩展坞连接手机；看到网口指示灯后再打开 APP。
零额外硬件

UDP 局域网无线

没有扩展坞或网线时无需手工切换。确保手机和电脑处于同一个局域网，Host 会自动发现并回退。

电脑同一路由器局域网 / Wi-FiUDP手机
  1. 手机与电脑连接同一个路由器。
  2. 先打开 VF Mobile，再打开 VFHost.exe。
  3. 不要同时使用会隔离设备的访客 Wi-Fi。
这里是 UDP，不是“UPD”。 网络传输只负责把画面送到手机；鼠标怎么输出由下一节单独设置，二者不要混为一谈。
03

鼠标控制路线

MAKCU 与蓝牙 HID 二选一

有盒子时选择

MAKCU 有线盒子

电脑 USB← 左侧口MAKCU中间线 →手机扩展坞

MAKCU 右侧口 → 鼠标接收器或有线鼠标插头

  1. 按盒体正面朝向确认左、中、右位置；若实物有丝印，以丝印为准。
  2. APP“控制”页选择“MAKCU 有线盒子”。
  3. 等待路线状态显示已就绪，再测试移动。
没有盒子时选择

蓝牙 HID 无线

  1. 打开手机蓝牙。
  2. 在 APP“控制”页选择“蓝牙 HID 无线”。
  3. 打开电脑蓝牙，添加设备并与手机完成配对。
  4. 回到 APP；未显示“已就绪”时点击“重新检测”。
04

开始推流

严格按这个顺序启动

  1. 1
    先打开 VF Mobile

    保持在“推理”页，看到“等待主机连接”。

  2. 2
    再打开桌面 VFHost.exe

    等待手机端点与当前链路完成自动检测。

  3. 3
    确认链路

    有线应显示 CAT6；没有有效有线端点时应显示无线自动回退。

  4. 4
    点击“开始传输”

    首次出现系统授权提示时，只允许官方交付的当前 VFHost.exe。

05

第一阶段验收

先确认网络和画面正常

保持 15–30 秒，检查这些状态

  • Host 的手机端点不再显示“尚未检测”。
  • Host 捕获、编码、发送指标开始出现数值。
  • 手机“接收画面 / 处理画面 / AI 推理”不再等待。
  • 手机新画面接收、解码、推理 FPS 持续大于 0。
  • 画面没有持续断开、黑屏或频繁重新连接。
只要网络还不稳定，就先不要测移动。 否则无法判断抖动来自网络、推理还是控制输出。
06

第二阶段验收

网络稳定后再测试移动效果

1

确认控制路线

MAKCU 或蓝牙 HID 必须显示“已就绪”。

2

确认模型与瞄准位置

选择对应游戏模型，再选择身体或头部。

3

先测单目标

在已授权的训练环境中先做小范围、低复杂度跟随。

4

再测目标切换

记录切换瞬间是否抖动、停顿、抽帧或丢失目标。

不要一上来同时改很多参数。 每次只改一个设置，并记录修改前后现象，反馈才有可比性。
07

日志反馈

手机和电脑日志都要发

手机

导出 VF Mobile 运行日志

  1. 问题出现后尽快回到 VF Mobile。
  2. 点击右上角齿轮形按钮；当前版本实际功能为“导出运行日志”。
  3. 在系统文件保存器中选择一个容易找到的文件夹。
  4. 确认文件名后点击右下角“保存”。
电脑

打开 VF Host 日志目录

  1. 先点击“停止传输”，不要先关闭 Host 窗口。
  2. 点击右上角“诊断与日志”。
  3. 系统会打开 %LOCALAPPDATA%\VisionForge\DualMachine。
  4. 复制 host-events.jsonl 与最新的 host-metrics-v6.csv。
  5. 如果 crashes 中有新文件，也一起发送；复制完成后再关闭 Host。
host-events.jsonl host-metrics-v6.csv crashes / 最新文件（如有）
发送前检查： 不要把卡密、无线调试配对码、账号密码或无关个人文件一起发送。日志太多时可把本次相关文件压缩为一个 ZIP。

常见问题快速对照

Host 找不到手机确认 APP 已打开；无线时检查同一局域网，有线时检查扩展坞与网口指示灯。
手机一直 0 FPS确认已点击“开始传输”，并检查 Host 捕获、编码、发送三项是否都有数值。
画面正常但鼠标不动检查 APP“控制”页的输出路线是否已就绪；这是控制链路问题，不是推流网络问题。
移动抖动或目标切换抖动记录模型、瞄准位置、触发方式、网络与控制路线，并同时发送手机与 Host 日志。
CAT6 未启用检查网线两端和扩展坞供电；程序会在没有有效有线手机端点时保持 UDP 无线回退。
